# Event Tracking API

## Concept

- **Account**: represents an API client, the application using this API; authenticates using API keys.
- **User**: just a string identifier generated by the Account; not a separate entity.

## Account Data

- `id`: unique identifier (UUID)
- `name`: application name
- `email`: contact email
- `login`: for admin panel access
- `password_hash`: hashed password for admin panel access (includes salt internally)
- `created_at`: timestamp of creation

## API Key Data (separate table)

- `id`: unique identifier (UUID)
- `account_id`: Account this key belongs to
- `key`: the API key string
- `active`: boolean flag for key status
- `created_at`: timestamp of creation

## Event Data

- `id`: unique identifier (UUID)
- `account_id`: Account this event belongs to
- `user`: string identifier of the end user (generated by Account)
- `api_key_id`: API key used to send this event
- `name`: event name
- `payload`: optional JSON payload
- `created_at`: timestamp of the event
